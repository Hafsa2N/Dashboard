Healthcare Dashboard 
key technologies we've used:
Framework: Next.js (using the App Router) with React for building the user interface.

Language: TypeScript for type-safe JavaScript.

Styling: Tailwind CSS for utility-first styling.

UI Components: ShadCN UI for the component library, which provides the building blocks for the user interface.

Generative AI: Genkit (specifically with the Google AI plugin) to power the AI features, like the alert summarizer.

Charting: Recharts for creating the data visualization charts.

Icons: Lucide React for the icon library.

Form Handling: React Hook Form and Zod for robust and type-safe form validation.
